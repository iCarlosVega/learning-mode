Rulings:

- Session cutoff will be represented by activation intervals rather than a single mutable timestamp so repeated ON/OFF cycles remain auditable.
- Project intent will be canonical in each project’s `.learning/intent.json`; global storage retains only identity and current path.
- Adapter host-session mapping will be stored explicitly because lifecycle hooks must resolve a stable Core session without observing prompt content.

- Task 10 assessment facade methods are deferred to Task 12, where the real assessment contract is implemented; placeholder methods would create a false public capability.
- Task 12 executes before Task 11 because Task 11 requires working `learn test request/record` commands that depend on the assessment service; this preserves a functional CLI surface at every commit.
- Skill pressure-test limitation: this environment exposes no agent spawn operation, so Tasks 16-17 use executable adapter scenarios, host validators, and static discovery checks instead of fresh-agent behavioral trials.
